## 🎯 Naming Convention

### Phase Reports
Format: `PHASE_[N]_[NAME].md`
Example: `PHASE_02_STATE_MANAGEMENT.md`
Location: `03_PHASE_REPORTS/`

### Module Reports
Format: `MODULE_[NAME].md`
Example: `MODULE_AUTH_SC_AUT_01_02.md`
Location: `04_MODULE_REPORTS/`

### Feature Reports
Format: `FEATURE_[NAME].md`
Example: `FEATURE_AUTH.md`
Location: `05_FEATURE_REPORTS/`

### Documentation Files
Location: `06_DOCUMENTATION/`
Format: `[DESCRIPTION].md`
Examples: `QUICK_START.md`, `DATA_FLOW_DIAGRAM.md`
